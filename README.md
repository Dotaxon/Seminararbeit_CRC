# Seminararbeit CRC

Dieses Repository entstand im Rahmen einer Seminararbeit zum Thema zyklische Redundanzprüfung (CRC).

Es enthält verschiedene CRC Implementierungen in C.

Als Referenzimplementierung ist Quellcode aus 'A Painless Guide to CRC Error Detection
Algorithms' beigefügt.

Gebaut wird das Projekt mit CMake. Die Referenzimplementierung wird mit Make gebaut.

Ebenfalls ist eine KI generierte Website dabei, die eine Hardware CRC Implementierung simuliert.
